Methodology / fixtures

Test values, with a source

Run orx-synthetic-v1. Source: seeded synthetic bars, seed 20261026. Dates: 30 Jul–5 Aug 2026. The six displayed bars are in-sample; run totals include the labeled in- and out-of-sample partitions.

Run costs: $1.24 round-trip commission per MNQ micro, one tick entry slippage and one tick stop slippage. These are fixture settings. No trading strategy was evaluated. Drawdown is the loss from the highest daily closing equity; it is shown with a minus sign.

The tables contain the values drawn above. Without JavaScript, all six bars and their tables remain visible. The sample picker is a control specimen. The replay controls only reveal these exported bars.
